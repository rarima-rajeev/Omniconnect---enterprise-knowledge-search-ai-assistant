On July 21 an AWS access key with ID ending AKIA-ROTATED-7731 was committed to a public GitHub repository by a contractor. GitHub secret scanning alerted us within four minutes. The key was revoked nine minutes after the commit.

CloudTrail review showed two calls from an unknown IP in the window, both `ListBuckets` requests that were denied by our S3 bucket policies. No data was accessed.

Actions: the contractor's access was suspended pending review, all contractor repositories now require pre-commit secret scanning, and long-lived access keys are being replaced with short-lived role credentials by end of Q4.
