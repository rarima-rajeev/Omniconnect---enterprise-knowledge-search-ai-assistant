Severity P2. On September 2 the ElastiCache Redis cluster `sessions-euw1` failed over twice in 52 minutes. After the 7.2 engine upgrade, `maxmemory` was left at the default for the old node type, so the new nodes hit out-of-memory evictions and the primary was marked unhealthy by Sentinel.

Impact: about 41,000 European console users were signed out. Duration 27 minutes of user-visible impact.

Fix: set `maxmemory` to 75% of node memory and `maxmemory-policy` to `volatile-lru`. Added a Terraform validation that blocks deploys when `maxmemory` is not set explicitly. Owner: Alex Rivera.
